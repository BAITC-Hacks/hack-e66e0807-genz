# Проверка результата на данных кейса

Этот документ фиксирует **измеренные** результаты для предоставленных трёх parquet. Проверки выполнялись 23 сентября 2026 года. Числа относятся к этой выгрузке и изменятся при других входных файлах. Роли, аномалии и маршруты — гипотезы для ручной проверки, не доказательство причастности или движения одних и тех же денег.

Финальная проверка одной командой `python3 run.py --skip-install --check` прошла; два независимых запуска CLI заняли **4,525 и 4,277 с**, существенно ниже ограничения кейса в 300 с. Это замер на текущей машине, а не гарантия времени на любом оборудовании. Три CSV побайтно совпали с сохранённым результатом до дополнительных аналитических функций (сохранённой перед расширением).

Отдельный валидатор `scripts/verify_extensions.py` заново читает parquet и проверяет содержимое каждого опубликованного маршрута, цикла, сценария устойчивости и аномального признака; последний запуск с сохранённой базой CSV завершился `PASS`. Девять адресных тестов проверяют порядок дат и усечение, канонизацию циклов, удаление узлов, пустой граф, самооперации и граничные группы сравнения.

## Как воспроизвести проверку

После установки зависимостей и расчёта через `python3 run.py --check` можно отдельно выполнить:

```bash
.venv/bin/python scripts/verify_temporal.py --data FINANCE-CASE/data --out output
.venv/bin/python scripts/verify_extensions.py --data FINANCE-CASE/data --out output
.venv/bin/python -m unittest discover -s tests -v
npm --prefix frontend test -- --run
npm --prefix frontend run build
```

Финальная сборка фронтенда и **33 теста** прошли; проектный прогон Python-тестов дал **45 PASS**. Независимые расчётные валидаторы выше запущены отдельно и прошли. Исходный код расчёта и интерфейса проверен на зашитые длинные gid: таких списков результатов нет. Архив исходников и локальный запуск документированы в [README](../README.md); испытание установки с нуля на другой операционной системе не проводилось.

AI-ассистент проверен реальным обращением к OpenRouter free: модель вызвала get_common_recipients; сервер подтвердил 5 плательщиков, 179 500 KZT и полный набор пяти ссылок на направленные рёбра (2,82 с). Также прошли реальный вопрос о приоритете выбранного gid и точный вопрос пользователя «Как отбираются участники для приоритета.». Последний проверен в браузере: показаны четыре веса, нормировка, правило сортировки, топ-50 и ссылка на реальный балл 0.837198. Ошибки формата и отсутствовавшего инструмента методики устранены; фактический текст и цитаты формирует сервер после настоящего вызова инструмента моделью. Без настройки провайдера основной граф, расчёт и выгрузки работают независимо от него. Подробнее: [AI-ассистент](AI-ASSISTANT.md).

## Репозиторий и публичные материалы

Финальный чистый архив исходников установлен без готовых .venv и node_modules: `python3 run.py --data <исходные parquet> --check` прошёл, два независимых CLI-прогона — 4,325 и 4,375 с, детерминированность CSV/JSON и HTTP подтверждены. Использован кэш пакетов; другой компьютер или ОС не проверялись. При первой установке требуется получение зависимостей, после подготовки core работает без интернета. Parquet предоставляются организатором отдельно, что явно описано в README.

README содержит одну команду запуска, все шесть правил ролей и пороги, выходные схемы, ограничения, масштабирование до миллиона узлов, схему решения и ссылку на пятиминутное демо с тремя реальными узлами. Архитектура и контракты опубликованы отдельно. Проверка относительных ссылок: отсутствующих ссылок нет; ссылок на внутреннее планирование нет. 71 внутренний файл планирования исключён из отслеживания, сохранён локально и в истории Git; среда, зависимости, ключи и модельные бинарники не отслеживаются. Отчёт 5,2 МБ — намеренный воспроизводимый артефакт сдачи.

Все пять обязательных пунктов кейса подтверждены. Все восемь дополнительных направлений представлены в явно описанном объёме: обрыв, даты, ограниченные маршруты/циклы, аномалии, устойчивость, реальный AI, карточка и запросы недостающих данных. Это не означает полноту поиска всех маршрутов, доказательство происхождения денег, проверку всех возможных вопросов AI или гарантию оценки жюри.
